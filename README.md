# Benešovka redesign V3

Směr:

- žádné eyebrow texty,
- žádné pastelové/křídové barvy,
- žádná univerzální SaaS kartičková šablona,
- žádné generické slogany,
- ostré, syté barvy vycházející z vizuálního jazyka původního webu,
- velká práce s fotografiemi a typografií,
- skutečné názvy a funkce školy,
- výrazná atletická identita,
- praktické odkazy pro rodiče a žáky vysoko na stránce.

Použito:

- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Archivo Black + Inter
- vanilla JavaScript

Fotografie:

- veřejné obrázky ze současného webu školy.

Logo:

- lokální asset z dodaného screenshotu.
